Virtual shelf — run on Windows, macOS, and Linux

You cannot take the Windows .exe to a Mac or Linux machine. Each OS needs its own copy.

Quick start (works on all three, needs Python 3)
-----------------------------------------------
Windows:  double-click start.bat
macOS:    chmod +x start.sh start.command && ./start.sh
          or double-click start.command
Linux:    chmod +x start.sh && ./start.sh

Linux extra (once):
  sudo apt install python3-gi python3-gi-cairo gir1.2-gtk-3.0 gir1.2-webkit2-4.1

Pack a portable app (run this ON that computer)
-----------------------------------------------
Windows:  build-app.bat   -> dist\VirtualShelf\VirtualShelf.exe
macOS:    ./build-app.sh  -> dist/VirtualShelf.app
Linux:    ./build-app.sh  -> dist/VirtualShelf/VirtualShelf

Copy the whole dist folder. Do not lift the binary out by itself.
A Windows PC cannot build the Mac or Linux app; build it on a Mac or a Linux box.

First launch in a new window: Export from the old shelf, then Import here.
